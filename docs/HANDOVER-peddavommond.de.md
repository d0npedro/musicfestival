### Critical: Vite base vs dist layout

With `VITE_BASE=/musicfestival/`:

| Browser requests | Files on disk in `dist/` |
|------------------|---------------------------|
| `/musicfestival/` | `index.html` |
| `/musicfestival/assets/*.js` | `assets/*.js` (no `musicfestival/` folder) |

`vercel.json` **must** strip the prefix for static files **before** any SPA fallback:

1. `/musicfestival/assets/:path*` → `/assets/:path*`
2. `/musicfestival` + `/musicfestival/` + `/musicfestival/:path*` → `/index.html`
3. Root SPA catch-all for non-asset paths

These rules are generated by shipped helper `vercelRewritesForBase('/musicfestival/')` in `src/deploy/basePath.ts` and must stay in sync with `vercel.json` (unit-tested).

Without the asset strip, JS URLs return `Content-Type: text/html` (SPA shell) and the game fails to load.

### Environment variables (Vercel → Project → Settings → Environment Variables)

|------|-------------------------------------|-------------------------------------|
| `VITE_BASE` | `/` or omit | `/musicfestival/` (must match public URL path) |

Redeploy after changing `VITE_BASE`. For peddavommond.de subpage, use the subpath column.

## Mount under **peddavommond.de** subpage

Intended public URL pattern:

```text
https://peddavommond.de/musicfestival/
```

(Trailing slash preferred; `VITE_BASE` must be `/musicfestival/`.)

### Option A — Separate Vercel project + path rewrite on the main site (recommended)

1. Deploy **this** repo as its own Vercel project.
2. Set project env **`VITE_BASE=/musicfestival/`** and redeploy (game host must serve the prefixed URLs via `vercel.json` strip rewrites above).
3. Smoke on the **game** host first:
   - `GET https://<game-host>/musicfestival/` → HTML with **Start Shift**
   - `GET https://<game-host>/musicfestival/assets/<hash>.js` → **`Content-Type` includes `javascript`** (not `text/html`)
4. On the **peddavommond.de** Vercel project (main site), proxy the subpath **keeping the `/musicfestival` prefix** so the game project can strip it:

```json
{
  "rewrites": [
    {
      "source": "/musicfestival",
      "destination": "https://musicfestival-nine.vercel.app/musicfestival"
    },
    {
      "source": "/musicfestival/",
      "destination": "https://musicfestival-nine.vercel.app/musicfestival/"
    },
    {
      "source": "/musicfestival/:path*",
      "destination": "https://musicfestival-nine.vercel.app/musicfestival/:path*"
    }
  ]
}
```

Helper: `parentProxyRewrites('/musicfestival/', 'https://musicfestival-nine.vercel.app')` in `src/deploy/basePath.ts`.

**Do not** rewrite parent `/musicfestival/assets/*` → game `/assets/*` while HTML still points at `/musicfestival/assets/*` on the parent host without a matching proxy — keep prefix end-to-end (parent proxy → game strip).

**Do not** use `VITE_BASE=/` on the game if public URLs are under `/musicfestival/` (absolute `/assets/` would hit the parent site).

### Option B — Subdomain

```text
https://festival.peddavommond.de/
```

- Set `VITE_BASE=/`
- Add the subdomain as a domain on this Vercel project
- No path rewrites needed

### Option C — Monorepo / single project output

If peddavommond.de builds multiple sites from one repo:

1. Place this app under e.g. `apps/musicfestival/`
2. Set Vercel **Root Directory** to `apps/musicfestival`
3. Set `VITE_BASE=/musicfestival/`
4. Ensure the parent site does not serve a conflicting `/musicfestival` route
